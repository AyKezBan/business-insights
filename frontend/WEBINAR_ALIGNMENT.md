# Уточнения вебинара и изменения интерфейса

Источник: локальный PDF «Вопросы с вебинара _ Новостная лента.pdf», 6 страниц, прочитан через OCR 22 октября 2026 года. Ниже — применимые к D09/D10 пункты, а не заявление о выполнении всего кейса.

| Пункты | Уточнение | Реализация / граница |
|---|---|---|
| 28, 31, 33 | Данные пользователя допустимы; роли полезны, но необязательны; не перегружать ввод | Имя, компания, должность в одном профиле; верхние селекторы убраны |
| 32 | Полномочия можно считать проверенными при входе в интернет-банк | Отдельная проверка полномочий не имитируется; в будущем данные сессии отдаёт backend |
| 40, 43 | Закрытый Alfa Research подключать не требуется; оценка банка нужна по релевантности; происхождение внешних выводов явно обозначать | Три отдельных аналитических блока. Если оценки банка нет, это видно в каждом разрезе. Настоящие предоставленные PDF ещё должен подключить D03 |
| 44, 48 | Различать факты, выводы модели и гипотезы; вывод модели не выдавать за официальную позицию банка | Факт вынесен отдельно, подразделы имеют метки типа содержания, у вывода компании есть пояснение о модели |
| 49 | Обязателен дисклеймер об отсутствии инвестрекомендации | Внизу правого блока источников короткая пометка и полная формулировка, во всех разрезах |
| 52–55, 58, 61 | Веб-раздел внутри оболочки банка с входом с главной; точная копия дизайн-системы и мобильный формат не обязательны | Существующая оболочка, главная и лента сохранены; добавлен Профиль |

| 63 | Демонстрационная авторизация рекомендована; физлицо может иметь несколько компаний | По запросу пользователя сделана только форма будущего входа. Настоящая/демонстрационная серверная авторизация и учётные записи ещё не реализованы |
| 69, 74 | Ограниченный набор подходит для показа UI, но итоговое решение должно масштабироваться | UI строит списки по bootstrap; синтетические ответы сервера не доказывают обработку всей выборки |

Изменения данных (выручка 2025, значения-заглушки, города обслуживания и платёжные периоды) относятся к D01 и конвейеру данных. В этом интерфейсном стенде CSV не используются; ложные новые выводы из этих уточнений не добавлялись. Уточнения по моделям/библиотекам и агентности относятся к D07/D11 и не потребовали смены frontend.

Перед сдачей остаются: настоящие источники и генерация содержания, банковская/демонстрационная сессия по решению команды, серверный профиль/обратная связь, визуальная приёмка в браузере. Необязательные пожелания вебинара не трактуются как новые обязательные компоненты.
