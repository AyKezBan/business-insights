# Схема PostgreSQL

SQL: `data-import/sql/schema.sql`. Все таблицы находятся в `bi_data` и содержат один текущий набор данных.

| Таблица | Ключ | Содержание |
| --- | --- | --- |
| `dataset_metadata` | `singleton=true` | Хеш набора, версия структуры, исходные файлы, время загрузки и описание периода. |
| `raw_company`, `raw_link`, `raw_payment` | `source_row` | Исходные записи как JSONB. |
| `company_ref` | `synthetic_u` | Все валидные ID компаний и статус доступности профиля. |
| `company_profile` | `synthetic_u` | 24 поля компании, статус выручки, страны и признаки качества; ссылки на реестр и raw. |
| `person_ref` | `synthetic_f` | ID физлиц из пригодных связей. |
| `person_company_link` | `source_row` | Связи ФЛ–ЮЛ и их география; ссылки на реестры и raw. |
| `payment_snapshot` | `row_id` | Участники, сумма, счётчик и признаки качества; ссылки на raw и реестр компаний. |

Деньги — `NUMERIC` без фиксированной шкалы, счётчики и номера записей — `BIGINT`, флаги — nullable `BOOLEAN`, ID и градации — `TEXT`, списки — `TEXT[]`. Пара участников платежа не является уникальным ключом.

Индексы покрывают группу компании, обе стороны связей и платежей. История наборов и автоматические миграции не реализованы.
