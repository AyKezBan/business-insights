# Результаты проверки

Ранее полный набор обработан в Python 3.12.14. Для независимой сверки пяти профилей использовался pandas 2.2.3; сам модуль его не требует.

| Показатель | Результат |
| --- | --- |
| Прочитано компаний / связей / платежей | 85 525 / 12 514 / 1 380 585 |
| Однозначные профили / реестр ID компаний | 85 513 / 204 708 |
| Неоднозначный ID | `U_428697`, 12 записей в исходном CSV; профиль не создаётся |
| Платежи, исключённые из агрегатов | 153, включая 26 строк с повторными парами |
| Выручка-заглушка | 601 профиль |
| Страны ФТС | 1392 исходные комбинации, 128 обозначений после разделения |

Хеши исходных файлов, суммы платежей, число операций и показатели качества сохраняются в `source_manifest` таблицы `business_insights.dataset_metadata`.

Все 6 unit-тестов прошли. Проверены: точные числа, флаги, страны, неоднозначные и внешние ID, повторные платежи, переводы себе, неизвестные значения, изменение источника и повреждённый CSV.

PostgreSQL не запускался. COPY, внешние ключи, повторный импорт и откат подготовлены к проверке интеграционным тестом, но работа на сервере пока не подтверждена. Команды — в `data-import/README.md`.
