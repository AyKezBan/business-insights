# Модуль импорта данных

Обрабатывает сырые CSV компаний, связей и платежей и загружает подготовленные записи в PostgreSQL. Сохраняет нормализованные значения, номера строк CSV, признаки качества и метаданные набора. Исходные CSV не дублируются в БД. Загрузка и замена данных выполняются атомарно.

Команды — в `data-import/README.md`, правила — в `data-import/docs/DATA_RULES.md`, структура таблиц — в `data-import/docs/SCHEMA.md`, статус проверок — в `data-import/docs/VALIDATION.md`.
