# Модуль импорта данных

Обрабатывает сырые CSV компаний, связей и платежей и загружает их в PostgreSQL. Сохраняет исходные поля, нормализованные значения, признаки качества и метаданные набора. Загрузка и замена данных выполняются атомарно.

Команды — в `data-import/README.md`, правила — в `data-import/docs/DATA_RULES.md`, структура таблиц — в `data-import/docs/SCHEMA.md`, статус проверок — в `data-import/docs/VALIDATION.md`.
