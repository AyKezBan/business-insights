# Общий локальный запуск Business Insights

Задание: запустить фактически существующие frontend, Java API, ML и PostgreSQL одной командой, сохраняя исходные CSV/PDF и существующие окружения. База — develop e105b7c; frontend — открытый PR #6, 7c59dd0, объединён только в изолированной ветке feature/full-stack-compose. PR #2–5 уже merged. feature/ml-finalize исследован, но не включён: это отдельная незавершённая разработка, её snapshot не содержит текущие backend/data-import.

Выбор реализации: Docker Compose в корне репозитория, PostgreSQL 17, существующий импортёр как обязательная одноразовая задача, Java Flyway при запуске backend, существующий ML image и nginx со статическим frontend и same-origin proxy. Публикуется только 127.0.0.1:8088. Nginx передаёт демонстрационный bearer backend; это локальный однопользовательский доступ, не банковская авторизация. Семь bindings переводят существующие Java DTO для текущего UI. Подготовка событий/анализов выполняется API, UI показывает сохранённую ленту.

Повторный up использует именованные project-scoped volumes; импорт идентичного набора no-op, замена и удаление данных не автоматизируются. CSV монтируются read-only. Материалы подключаются отдельным overlay с обязательной валидной версией корпуса; подготовка/проверка выполняются существующей CLI явными jobs. Модель и материалы не подменяются автоматически. Основной ML работает с реальным клиентом, пустой ключ не означает fixture-режим. Корпус не обязателен для поднятия процесса; ограничение видно в health и результате.

Приёмка: compose config, сборка образов, отдельный случайный project с синтетическими CSV и явно тестовым ML-клиентом, полный HTTP путь через frontend proxy/Java/ML/PostgreSQL, повтор импорта и перезапуск с сохранением результатов, негативная проверка изменённых CSV, отсутствие исходных секретов в image. Никаких live LLM вызовов, публичной публикации и изменения чужих БД. Native worktree tool вернул Not a git repository, поэтому использован ручной nested-repo worktree. Ruflo/ToolSearch недоступны среди инструментов, поиск по registry выполнен.
