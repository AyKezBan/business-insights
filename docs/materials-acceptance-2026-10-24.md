## Live-проверка и review

[Машиночитаемые результаты](../ml-service/eval/live-acceptance-2026-10-24.json) содержат run IDs, event IDs, профиль, статус и фактические checks без исходного/сгенерированного полного текста.

- Отложенные 10 материалов: 10/10 непустых первичных текстов, публикаций и сохранённых URL; 10 событий/версий. После development-пары не менялись prompts по содержимому holdout.
- Первый ограниченный прогон: Qwen не ответил за 55 с; GLM дважды исчерпал cap 4500 reasoning tokens без JSON. Локальный ограничитель остановил последующие попытки. Это не 6 успешных анализов.
- Gemma-only до исправления поиска: 4 limited, 2 failed; найдено нерелевантное совпадение банка по слову «риск». Этот случай стал regression: общие слова/годы без предметного lexical anchor не дают evidence. Gold после изменения остаётся 10/10; цена фильтра — отказ на слишком общих запросах.
- Финальный прогон после исправлений, на двух других статьях × 3 профиля: **5 limited, 1 failed**, 22 LLM-вызов. У failed модель сначала вернула схему, затем объект с отсутствующим обязательным level. В limited удалены claims с неверными IDs/features/числами либо недостаточными основаниями. Полные ответы и traces сохранены локально.
- **A10 не принят.** При ручной оценке одного inference модель перепутала эмитентов облигаций с участниками манипуляций. В других ответах персонализация слабая или разделы потеряны после проверки. Наличие source ID и совпадающих чисел не доказывает смысловое следование. Это проверяемые задачи для совместной работы с владельцем agent/personalization; сквозной MVP не заявлен готовым.
- Проверенный вариант подключения — разрешённая Gemma для обеих ролей; env example обновлён. Qwen/GLM требуют отдельной калибровки timeout/output/reasoning. Дневной денежный остаток ключа не подтверждён, token/raw-cost guards не считаются его доказательством.

Независимый code review завершён: 2 Important implementation findings и 1 Important plan defect. Все воспроизведены failing tests, исправлены, полный набор 115/115. Конфликты найденных новостей теперь попадают в prompts, limited/provenance и QA; одинаковые наблюдения batch выбирают максимальный retrieved_at; поздний импорт сравнивает времена получения источника вместо времени импорта. Повторное подтверждение текущего текста обновляет last retrieval без новой версии. Цена решения: корректность времён producer остаётся предпосылкой. Critical/Minor замечаний не осталось. Review не подменяет браузерную и совместную смысловую приёмку.

## Решения и ограничения

- Изолированный Git worktree создан вручную: native tool не распознал вложенный repo. Исходный detached checkout восстановлен; рабочие изменения не потеряны. Стоимость решения: жизненный цикл worktree нужно обслуживать обычным Git.
- Заголовки задач нормализованы для task helpers; исторические материалы S1–S10 остаются в исходном локальном пакете. Команды реализации самодостаточны. Стоимость: исходные исследовательские вложения не доступны в clone.
- OCR 300 DPI ограничен 3000px, чтобы не увеличивать низкое разрешение исходного скана без пользы. Docker-проверка выполнялась параллельно чистым тестам corpus; это не считалось завершением OCR до реального прогона. Стоимость: мелкий текст всё равно требует визуальной сверки.
- SourceVersion.active добавлен отдельно от revision: поздний импорт исторической статьи не откатывает текущую версию. Неупорядоченные разные версии URL в одном batch отклоняются. Стоимость: producer должен сохранять retrieval timestamps.
- Ручные OCR corrections версионируются; hash-bound review изменённого утверждения сбрасывается. Стоимость: исправленные фрагменты требуют новой сверки.
- Старый consumption paragraph содержит два прогноза конца 2026. Пересмотр ставки исключает весь старый фрагмент с даты новой публикации. Это консервативно: его компонент прогноза инфляции тоже больше не используется.
- Только точные копии объединяются автоматически. Семантические перефразы и сходимость ранее разных event IDs требуют явной группировки. Runtime проверки чисел/единиц не доказывают entailment; смысловое качество нельзя вывести из числа тестов.

Полные PDF/OCR/статьи/review images, traces и live outputs остаются локально, исключены из Git. Ключи не копируются в репозиторий и не выводятся.
