## Ограничения и решения

- `as_of` ограничивает дату публикации. Это не бивременная рыночная история: более позднее наблюдение исправленной страницы получает явное ограничение, а не выдуманную дату знания.
- Только точные копии объединяются автоматически; semantic clustering, embeddings, archive backfill и дополнительные издатели не входят в согласованный finish scope.
- Span фиксирует Unicode code points и SHA256 конкретного текста. Смысловая модель-верификатор проверяет выводы, но её verdict не является доказательством истины; обязательна независимая живая приёмка.
- Native worktree tool не распознал вложенный репозиторий; использованы отдельные Git worktrees. Цена решения — ручное обслуживание их жизненного цикла. Исходный checkout оставлен в прежнем состоянии.
- Разрешённая пользователем параллельная работа шла в трёх чатах с отдельными worktrees и владельцем каждого общего интерфейса. Цена решения — дополнительные интеграционные проверки после слияния.

Полные PDF/OCR/статьи, изображения review, клиентские CSV, ключи, запросы, ответы и traces остаются локально вне Git. В репозитории публикуются только методика и проверяемые metadata.
