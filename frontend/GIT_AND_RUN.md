# Как передать D09/D10 в Git и запустить проект

Инструкция относится к папке **d09_d10_mvp** — учебному frontend прототипу и локальному Python-серверу. Все компании, новости и аналитические тексты синтетические. Авторизация, LLM и реальные банковские данные не подключены.

## Файлы проекта

| Путь | Назначение | Нужен для запуска |
|---|---|---|
| server.py | Раздаёт HTML/CSS/JS и обслуживает локальный JSON API. Точка запуска приложения. | Да |
| web/index.html | Оболочка: меню, верхняя панель, экран приложения. | Да |
| web/app.js | Навигация, профиль, карточка, аналитические разрезы, источники, уточнения, обратная связь и скрытие событий. | Да |
| web/styles.css | Стили, компоновка, адаптация интерфейса. | Да |
| requirements.txt | Сторонних Python-зависимостей нет; приложение работает на стандартной библиотеке. | Сохранить в проекте |
| .gitignore | Исключает кеш Python и временные результаты проверки. | Рекомендуется |
| Dockerfile, compose.yaml | Сборка и запуск приложения в Docker Compose. | Только для Docker |
| tests/test_api.py | Проверяет API, контексты, карточку, ссылки, ошибки и источники. | Не для запуска, включить в Git |
| tests/test_frontend.cjs | Проверяет сохранение профиля, вкладки, уточнения, обратную связь и скрытие событий. Node.js нужен только этому тесту. | Не для запуска, включить в Git |
| README.md | Краткое описание и быстрый запуск. | Рекомендуется |
| GIT_AND_RUN.md | Эта инструкция: состав Git, настройка и запуск на другом компьютере. | Рекомендуется |
| API_CONTRACT.md | Формат запросов и ответов frontend/API. | Для интеграции; включить в Git |
| THEORY_AND_DESIGN.md | Теоретическое обоснование; содержит историю версий. | Для обсуждения; включить в Git |
| WEBINAR_ALIGNMENT.md | Какие уточнения вебинара учтены и что пока не реализовано. | Для обсуждения; включить в Git |
| THIRD_PARTY_NOTICES.md | Уведомления о сторонних компонентах. | Включить для комплекта хакатона |
| VALIDATION.md | Результаты и границы проверок. | Рекомендуется |

Демонстрационные компании, события и источники находятся в константах COMPANIES, EVENTS и SOURCES внутри server.py. Отдельные CSV и база для старта не требуются.

## Состав Git

Добавьте папку d09_d10_mvp целиком, сохраняя относительные пути:

~~~text
d09_d10_mvp/
├── .gitignore
├── API_CONTRACT.md
├── compose.yaml
├── Dockerfile
├── GIT_AND_RUN.md
├── README.md
├── requirements.txt
├── server.py
├── THEORY_AND_DESIGN.md
├── THIRD_PARTY_NOTICES.md
├── VALIDATION.md
├── WEBINAR_ALIGNMENT.md
├── tests/
│   ├── test_api.py
│   └── test_frontend.cjs
└── web/
    ├── app.js
    ├── index.html
    └── styles.css
~~~

Если репозиторий команды уже есть — положите туда папку проекта в согласованное место. Если для прототипа создаётся отдельный репозиторий, содержимое папки d09_d10_mvp можно сделать корнем нового репозитория; тогда команды запускаются из корня клона.

Не добавляйте __pycache__, файлы *.pyc, папку validation, zip-архивы рядом с исходниками, логи и настоящие пароли. Первые три пункта уже указаны в .gitignore. Ключей API в приложении нет. Для приватного GitHub-репозитория участникам, в том числе жюри, нужно отдельно выдать доступ в настройках GitHub.

Перед отправкой проверьте, что Git видит нужные файлы:

~~~powershell
git status --short
git diff --check
git ls-files
~~~

## Запуск на Windows без Docker

Нужен Python 3.11 или новее. Node.js нужен только для запуска frontend-теста.

1. Клонируйте репозиторий, заменив адрес на URL проекта команды:

~~~powershell
git clone <URL-репозитория>
cd <имя-репозитория>d09_d10_mvp
~~~

Если d09_d10_mvp является корнем отдельного репозитория, перейдите просто в папку клона. Убедитесь, что Python доступен:

~~~powershell
python --version
~~~

Запустите приложение из папки проекта:

~~~powershell
python server.py
~~~

Откройте **http://127.0.0.1:8766**. Интерфейс и API запускаются вместе; отдельная команда для frontend или установка пакетов не нужны. Окно сервера оставьте открытым, пока работаете с приложением. Остановка — Ctrl+C в этом окне.

Чтобы использовать другой порт: python server.py --port 8770, затем откройте http://127.0.0.1:8770. Для показа загрузки с задержкой: python server.py --delay 2.

## Запуск на macOS и Linux

Нужен Python 3.11 или новее. Перейдите в папку проекта и выполните:

~~~bash
python3 server.py
~~~

Откройте http://127.0.0.1:8766. Остановка — Ctrl+C.

## Запуск через Docker Compose

На компьютере должны быть установлены и запущены Docker Engine и Docker Compose. Из папки проекта:

~~~powershell
docker compose up --build
~~~

Откройте http://127.0.0.1:8766. Docker Engine недоступен при подготовке инструкции, поэтому этот вариант локально не проверен. При ошибке запускайте напрямую через Python.

## Тесты после клонирования

Из папки проекта:

~~~powershell
python -m unittest discover -s tests -v
node --check web/app.js
node tests/test_frontend.cjs
~~~

Python-тест запускает временный API-сервер самостоятельно. Frontend-тест требует Node.js, поднимает сервер на свободном порту и использует тестовый DOM-адаптер; он проверяет поведение, но не визуальную раскладку настоящего браузера. Для обычного показа тесты не нужны.

## Что увидит другой человек

- Откроется уже заполненный синтетический демопрофиль. В разделе «Профиль» можно выбрать демонстрационную компанию, должность и имя; данные профиля хранятся в localStorage этого браузера.
- Компания и должность из URL не переопределяют профиль.
- Форма входа по логину и паролю — макет. Авторизация не работает. Форма очищает пароль и сообщает, что не отправляет и не сохраняет его. Не вводите туда настоящие учётные данные.
- «Позиция банка», новости и ответы демонстрационные. Реальные отчёты Альфа-Банка и нейросеть не подключены.
- Отзывы о полезности и скрытые события хранятся локально в браузере и не передаются разработчикам.
- Сброс демопрофиля и настроек выполняется очисткой данных сайта для origin http://127.0.0.1:8766 в настройках браузера.

## Частые проблемы

- **Address already in use:** порт занят. Запустите сервер с другим портом, например 8770, и откройте URL с тем же портом.
- **python не найден:** установите Python 3.11+ и проверьте, что он доступен в терминале. В некоторых системах команда называется python3.
- **Не удаётся открыть сайт:** убедитесь, что сервер запущен и порт в браузере совпадает с портом сервера.
- **Не работает интерфейс:** откройте адрес локального сервера, а не файл index.html напрямую; затем обновите страницу.

Формат API описан в API_CONTRACT.md. Перечень проверок и их ограничений находится в VALIDATION.md.
