## Запуск

Из папки d09_d10_mvp: 

~~~powershell
python server.py
~~~

Открыть http://127.0.0.1:8766. Python 3.11+, сторонних пакетов нет. Остановка — Ctrl+C. Другой порт: python server.py --port 8770. Для проверки ожидания: python server.py --delay 2.

Docker: docker compose up --build. Docker Engine в доступной среде не проверен.

## Текущий интерфейс

- Меню: Главная → Профиль → Бизнес-события. Вход с главного экрана сохранён.
- Выбор компании и должности перенесён в Профиль. Верхних селекторов и блока «Ваш контекст» больше нет.
- В профиле: имя, компания, отрасль, должность, сохранение настроек в этом браузере.
- Форма логина и пароля — интерфейс будущего входа. Нажатие «Войти» показывает, что авторизация пока не подключена. Пароль очищается, не отправляется и не сохраняется. Демопрофиль доступен без входа.
- Карточка: факт события, «Аналитика по открытым источникам», «Аналитика от Альфа-банка», «Вывод для компании».
- У каждого из трёх аналитических блоков есть «Последствия», «Риски», «Рекомендации».
- «Общий обзор» показывает всё. Остальные вкладки показывают только соответствующий подраздел во всех трёх аналитических блоках в том же порядке.
- «Уточнить по этому событию» сохранено и работает во всех разрезах.
- Справа, внизу «Основания и источники»: «Не является инвестрекомендацией» и «Аналитика не является инвестиционной рекомендацией».
- По уточнениям вебинара добавлены явные метки происхождения и гипотез, скрытие/возврат событий и обратная связь «Полезно / Не полезно».

Все компании, события, источники и ответы остаются синтетическими. Настоящие PDF/CSV не импортированы. Заголовки показывают будущую структуру продукта; LLM и настоящая банковская аналитика ещё не подключены. Отсутствие материала банка обозначается отдельно, без выдуманной оценки.

## Контекст и хранение

Компания и должность берутся из сохранённого профиля; старые company_id/role в URL игнорируются и удаляются при нормализации маршрута. В URL остаются экран, событие и view. Старое view=actions переводится в recommendations.

Профиль сохраняется в localStorage под d09-d10-profile-v1. Скрытие и обратная связь — под d09-d10-preferences-v1 с привязкой к компании, должности и событию. Вопросы и пароли туда не пишутся. Если браузер запрещает запись, UI сообщает об ошибке и не утверждает, что изменение сохранено.

Эти настройки действуют в данном браузере и origin (смена порта создаёт отдельное хранилище). Они не являются аутентификацией или проверкой полномочий. В будущем профиль и доступные компании нужно получать из банковской сессии. Один пользователь может иметь несколько доступных компаний — выбор допустимо разместить внутри профиля.

## Демонстрация

1. Главная → Бизнес-события → событие о ставке.
2. В Общем обзоре сравнить три блока аналитики и их происхождение.
3. Последовательно открыть Последствия, Риски, Рекомендации: каждый раз видны три источника аналитического взгляда.
4. Задать вопрос в «Уточнить по этому событию»; запросить денежный эффект без исходных данных и увидеть отсутствие достоверного ответа.
5. Открыть Профиль, выбрать учебную энергетику и должность CEO, сохранить. Вернуться к событию: персональный вывод изменится.
6. Перезагрузить страницу: профиль восстановится. Старый URL с другой компанией не подменит его.
7. Ввести тестовые значения в форму входа: она сообщит о неподключённой авторизации. Не вводите реальные банковские учётные данные в учебную форму.
8. Оценить аналитический материал, скрыть событие в ленте и вернуть его через «Показать скрытые».
9. Для пустой ленты сохранить в профиле «Новая компания».
