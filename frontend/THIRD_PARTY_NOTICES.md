# Сторонние компоненты

Прототип использует стандартную библиотеку Python и браузерные API. Сторонние npm/Python-пакеты, шрифты, изображения и CDN не подключены. Python распространяется по PSF License. Docker-образ python:3.11.9-slim включает Python и Debian; их лицензии и уведомления сохраняются в базовом образе. Код прототипа не устанавливает лицензию общего проекта — её согласует команда. Название Альфа-Бизнес используется для обозначения учебного сценария хакатона; официальный дизайн и логотип не импортированы.
